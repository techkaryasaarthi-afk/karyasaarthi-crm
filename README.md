# Karya Saarthi Unified CRM

Unified CRM repository for `karyasaarthi.com`, `karyasaarthi.in`, `career.karyasaarthi.com` and mobile applications.

## 📁 Repository Structure
- `backend/`: NestJS + Prisma + PostgreSQL (CRM Core API & Database)
- `frontend/`: Next.js 14 App Router + Tailwind CSS (Staff Admin Console)
- `docs/`: Architecture diagrams, ER models, API documentation
